# -----------------------------------------------------------------------------
# Ce fichier contient les allèles de référence connus pour chaque marqueur.
# Chaque ligne correspond à un allèle connu, avec sa taille théorique attendue.
# 
# ✅ Format obligatoire (7 colonnes, séparées par des tabulations) :
#   - marker    : nom du marqueur (ex : D8S1179, Bibl18, etc.)
#   - fluo      : fluorochrome utilisé (ex : FAM, HEX, NED, PET, etc.)
#   - mix       : nom du mix (ex : Mix1, Mix2, etc.)
#   - allele    : nom ou numéro de l’allèle (peut être 101, 132a, etc.)
#   - pb        : taille attendue en paires de bases (ex : 145.51)
#   - se        : erreur standard associée à la taille (ex : 0.4)
#   - couleur   : couleur visuelle associée au fluorochrome (ex : Bleu, Rouge)
#
# ⚠️ Ne pas modifier l’ordre ou les noms des colonnes.
# ⚠️ Le séparateur doit être une tabulation (fichier .txt).
# =============================================================================
#
